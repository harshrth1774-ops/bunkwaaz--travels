# BUNKBAAZ: Tourism Website

A simple, responsive tourism website covering three Indian states: **Rajasthan, Uttar Pradesh and Haryana**.

## Features
- Mobile-first layout based on the Wanderlust reference screenshot
- Hero with call-to-action, hamburger menu, three state columns with famous spots
- Keyboard-friendly menu (Escape closes it)

## Tech
HTML5, CSS3, Vanilla JavaScript, Google Fonts (Plus Jakarta Sans)

## Structure
```
index.html
css/style.css
js/main.js
assets/images/   (illustrations; replace with real photos)
```

## Run locally
Open `index.html` in a browser.

## Images
The images are simple SVG illustrations, not photographs. To use real photos, add them to `assets/images/` and update the `src` in `index.html`. Use photos you have the right to use (your own, or Wikimedia Commons / Unsplash with credit) and list them under Credits below.
